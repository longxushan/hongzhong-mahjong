## 一、项目定位

单机 4 人（1 玩家 + 3 AI）巢湖-金华红中麻将 H5。交付形态：**单文件 HTML5、零外部依赖**（牌面 SVG data URI 内联、音效/BGM WebAudio 合成、人声走 voice/ 语音包），双击本地可开、静态服务器可部署。无联网联机、无后端。

## 二、规则基线终版（锁定，详版见 docs 主文档「二」）

- **牌**：万/条/筒 1-9 各 4 张 + 红中 4 张 = 112 张；无风箭花。牌墙留底 6 张，流局只结算杠分。
- **红中（癞子）**：可代任意牌；打出的红中不能被碰/杠/胡；打出后胡牌按 2ⁿ 翻倍（1×2 / 2×4 / 3×8 / 4×16）；**手里 ≥2 只红中未打出时禁止胡牌**（blockedByZRule 硬闸，优先于一切胡牌判定，天胡/地胡资格同样作废）。
- **操作**：不能吃、可碰（≤4 组副露）、明杠/暗杠/补杠；**只能自摸胡，不能点炮**（例外：抢杠胡，手中有红中不可抢）。
- **起手与坐庄**：每桌首局掷骰定东（四人各掷两骰取和最大者为东，平局加掷至多 5 轮）→ 东家再掷 s 以东为 1 数位定庄；此后谁赢谁坐庄（流局按序轮换，非首局不再掷骰）。
- **大牌**：天胡（庄家起手 14 张即胡）×4、地胡（非庄第一巡摸牌即胡）×2，可主动不胡；起手基数有红中 2 / 无红中 3；翻码红中翻 4 / 硬胡翻 6、1/5/9 各 1 分。
- **牌型番**：七对 ×2、豪华七对 ×4、碰碰胡 ×4、清一色 ×2、杠上花 ×2、抢杠胡（可叠加连乘）。
- **计分**：基础分 = 3 − 有红中 1 − 有副露 1（最低 1）+ 翻码 + 番型连乘；**单局封顶 50**（天胡×4 等连乘后仍封顶）；杠分另计（暗杠每家 2 / 补杠每家 1 / 放杠 1 家出 2）。
- **轮次**：每人起底 100 子、8 局一轮、同桌固定；局末四家摊牌（流局摊四家、胡牌摊其余三家）；第 8 局终局弹总分榜。

## 三、AI 策略栈（六层，自上而下裁决优先级递减）

1. **L0 红中硬规则**：≥2 红中未打 → 强制先打红中（shouldDumpSingleZ / blockedByZRule），先于一切策略。
2. **L1 向听精算**：calcShanten 两层穷举（standardWin 顺子刻子 / allPongWin / isSevenPairs + 红中万能），masterDiscard 按"打出后最小向听 + 有效进张加权"选牌；向听逻辑锁定不动。
3. **L2 大牌姿态引擎**（bigHandStance）：手牌成型度达标时锁定清一色/七对/碰碰胡/组合姿态（清碰 ×8、清七 ×4、≥2 刻优先碰碰 ×4）；姿态达成后契合权重 ×25，敢于拆搭做牌（安全闸：最多慢 safeGap 步）；七对姿态拒一切碰杠、清一色别色不碰。
4. **L3 性格风格**（七风格，角色与性格固定绑定）：龙须山人 learning(进修)、福星道人 grand(大牌)、曹大师 academic(学院)、僧大兴 conservative(保守)、华少 aggressive(激进)、厨建国 flexible(灵活)、梅姐 steady(沉稳)；RISK 表（safeGap/pengTol/boost）按性格控制冒险度；STANCE_SAY 姿态宣言（走字幕）。注意：玩家所选角色不挂风格（座位 0 style=null 走灵活默认）。
5. **L4 观察与应对**（observeTable / readOpponents）：读弃牌河推别家缺门与危险牌、识别威胁家（听牌信号）→ 防守切安全牌、抢节奏提前碰杠、路线拥挤时转向；guard 情境闲聊台词联动。
6. **L5 双大师技巧层**（2026-11-11 AI 牌技升级，均只读公开信息、不偷看手牌、不改向听逻辑与 112 张守恒）：
   - **郑太顺层**（ztsKeepBonus/ztsDanger/ztsClaimGate）：金三银七保留偏好、同线加减一猜牌+反常对信号→危险牌避让、跟线半熟奖励、碰牌五不碰闸（复合型/大肚子/已听贪碰/短牌防守）。
   - **雀学米高层**（qxmgDeadMeldN/QXMG_LEVEL，tie-break 级偏置）：①死搭止损（进张存量≤1 的搭子每巡吃净值，等向听时优先拆）；②机会成本（对子≥4 拆对扣分护七对潜势）；③大牌小牌期望（中后期向听≥2 大牌姿态补贴×0.55）；④攻守时机（开局 16 弃牌内防守门槛抬高——防守选择权一直在，过早丢掉的进攻价值无法挽回）。
   - **角色修炼等级 QXMG_LEVEL**（AI 并非人人满级）：grand/academic 1.0、aggressive 0.9、flexible 0.8、steady 0.75、conservative 0.65、learning 0.55（成长线）；masterqx 闲聊事件七风格各两句（拆死搭时 30% 概率冒大师口径台词，语音缺文件自动跳过）。
   - 牌理口径：死搭按实牌进张判定（红中百搭价值已在 L1 精算覆盖不重复计）；性能上 27 项进张存量缓存表避免重复遍历牌墙。

**辅助系统**：
- **教学/师傅**（teachPick / handDiagnose）：向听主导推荐、绝不拆成型面子、大牌方向自主决断不报"打亏"；底部五栏面板（牌型分析/推荐打出/打牌建议/听牌一览/积分排行）；打错提醒、讲思路、复盘知识库。
- **听牌口径**：玩家显示用 **visibleLeft**（可见口径 4−废牌区−副露−自己手牌，2026-11-10 用户定义）；AI 精算用 tileRemaining（牌墙真实口径）——两口径并存、互不干扰。
